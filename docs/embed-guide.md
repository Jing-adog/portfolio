# 手把手教程：嵌入图片与视频

这份教程假设你完全没有代码经验，每一步都写了「在哪点、看到什么、输入什么」。跟着做第一遍之后，后面就会很快。

---

## 0. 先装一个编辑器（5 分钟，只装一次）

改网站内容 = 用编辑器打开 HTML 文件改几行字。**不要用 Word**（会改坏文件），记事本能用但容易出问题。

**推荐 VS Code**（微软出品、免费）：

1. 打开 <https://code.visualstudio.com> → 点 **Download for Windows** → 下载后双击安装，一路「下一步」即可
2. 安装好后打开 VS Code → 按 `Ctrl+Shift+P` → 输入 `language` → 选 **Configure Display Language** → 选 **中文(简体)** → 重启 VS Code，界面就变中文了
3. 菜单栏 **文件 → 打开文件夹** → 找到并选中 `作品集杂志版` 文件夹 → 左侧会出现所有文件的列表，点文件就能打开

> 实在不想装：右键 HTML 文件 → 打开方式 → 记事本，也能改。但 VS Code 一次安装，以后每次改内容都舒服得多。

## 1. 核心原理（先看懂，再动手）

1. 页面上每个**灰底灰字的长方块**就是「占位块」，它在文件里是一行文字代码，例如：

   ```html
   <span class="ph ph--square">作品占位 · 01</span>
   ```

2. 「嵌入一张图片」= **把这一行换成图片代码**，指向你放进文件夹里的图片文件。
3. 方块的比例由 `class` 里的 `ph--xxx` 决定，图片会自动裁切填满——所以你只需要关心「这个位置原来是几比几」，不用管图片本身多大。

| 占位块上写的比例 | class 用 | 例子 |
|------|------|------|
| 1:1 | `ph--square` | 绘画插画组 |
| 3:4 | `ph--portrait` | 摄影实拍、海报、关于我照片、账号截图 |
| 16:9 | `ph--wide` | 首页精选、运营成果截图、横屏视频 |
| 9:16 | `ph--9x16` | 竖屏快照、竖屏视频 |

4. **为什么部署后别人能看到**：图片文件放进项目文件夹内（`assets/images/`），页面用相对路径引用（`assets/images/xxx.jpg`）。部署时整个文件夹上传到 GitHub，访客打开网页时照片跟着加载。如果图片留在桌面，别人打开就是空白。

## 2. 嵌入一张图片（跟着做一遍）

以「审美习作页作品 01」为例，完整流程：

### 第 1 步：把图片放进项目文件夹

1. 在文件资源管理器里找到你的图片文件 → 右键 **复制**
2. 打开 `作品集杂志版 → assets → images` 文件夹 → **粘贴**
3. 右键粘贴进来的文件 → **重命名**，改成 **小写英文 + 数字 + 格式后缀**，例如 `works-01.jpg`

   - ✅ 可以：`works-01.jpg`、`photo-2.png`、`xiaohongshu-01.jpg`
   - ❌ 不行：`作品一.jpg`（中文）、`Works 01.JPG`（大写 + 空格）
   - 格式 `.jpg` 和 `.png` 都可以。文件夹里已有的 `portrait-01.jpg` 就是标准范例

### 第 2 步：在 VS Code 里找到要替换的位置

1. VS Code 左侧文件列表点开 `works.html`
2. 按 `Ctrl+F`，输入「作品占位 · 01」，回车——光标会跳到对应行
3. 占位块长这样：

   ```html
   <span class="ph ph--square">作品占位 · 01</span>
   ```

   （每个占位块上方都有一行 `<!-- CONFIG: ... -->` 注释说明这里该放什么，可以读一下）

### 第 3 步：整行替换

1. 用鼠标**选中占位块整行**（从 `<span` 开始到 `</span>` 结束），按 `Delete` 删掉
2. 在原来的位置粘贴这行（**只改两处：文件名、alt 引号里的说明文字**）：

   ```html
   <img class="ph ph--square" src="assets/images/works-01.jpg" alt="作品标题">
   ```

   - `class` **照抄不动**——它是 1:1 的比例（如果占位块上写的是 3:4，就写 `ph--portrait`，以此类推）
   - `src="assets/images/xxx.jpg"`——`xxx.jpg` 必须和你在第 1 步重命名的文件名**一字不差**
   - `alt="作品标题"`——写一句图片内容说明，面试官网慢没加载出图时会显示这段文字

### 第 4 步：保存 → 刷新 → 验收

1. 按 `Ctrl+S` 保存
2. 回到浏览器，按 `F5` 刷新页面
3. 看到照片出现在原来的灰块位置、比例正常 = 成功 🎉

---

## 3. 换掉已经嵌入的照片（换图不换代码）

1. 新图片复制进 `assets/images/`，**重命名成和旧图完全一样的名字**（如 `portrait-01.jpg`）
2. 系统提示「是否替换同名文件」→ 点 **替换**
3. 浏览器 `F5` 刷新，新图就生效了。代码一个字都不用改。

（或者保留两个文件，改 HTML 里 `src="assets/images/新名字.jpg"` 也行。）

---

## 4. 删掉占位说明文字

换好图后，如果图片下方还有一行小字「照片占位：××」/「视频占位・××」，选中那整行（以 `<figcaption` 开头、`</figcaption>` 结尾）删掉即可。这是占位阶段的临时标记，**部署前必须全部删干净**。

---

## 5. 关于我页的照片切换器（特殊一点）

照片切换器是三张叠放的卡片，点箭头/圆点切换。**第 1 张已嵌入你的真实照片**，第 2、3 张操作方式完全一样：

1. 在 `about.html` 里 `Ctrl+F` 搜「照片占位 · 工作照」和「照片占位 · 活动照」
2. 把那一行的 `<div class="ph ph--portrait">…</div>` 换成：

   ```html
   <img class="ph ph--portrait" src="assets/images/work-photo.jpg" alt="工作现场照">
   ```

3. 删掉图下方的「照片占位：工作现场照」说明词

**想加第 4 张照片？** 别自己复制（涉及圆点按钮联动，容易漏）——把照片发我，我来加。

## 6. 嵌入视频（运营账号页视频号面板）

### 第 1 步：准备 MP4 文件

- 只支持 **MP4 格式**（`.mp4` 后缀）
- 手机拍的视频传到电脑：微信里用「文件传输助手」发给自己，会自动压缩，文件控制在 **20MB 以内**最好（太大访客加载慢）
- 复制进 `作品集杂志版 → assets → videos` 文件夹，重命名小写英文，如 `channels-01.mp4`

### 第 2 步：替换占位块

1. VS Code 打开 `accounts.html`，`Ctrl+F` 搜「视频占位」
2. 会找到三条（横屏 16:9 一条 + 竖屏 9:16 两条）。**横屏那条**（占位块写 16:9）换成：

   ```html
   <video class="ph ph--wide" controls src="assets/videos/channels-01.mp4"></video>
   ```

   **竖屏两条**（占位块写 9:16）把 class 换成 `ph--9x16`：

   ```html
   <video class="ph ph--9x16" controls src="assets/videos/channels-02.mp4"></video>
   ```

3. 删掉视频下方的「视频占位・…」说明文字

### 第 3 步：保存并试看

`Ctrl+S` → 浏览器 `F5` → 页面上会出现播放器，点一下播放按钮确认能放。

---

## 7. 灯箱大图（作品 07 / 08 长图，进阶）

审美习作页作品 07、08 是长图：网格里显示封面小图，**点开灯箱后可以上下滚动看完整长图**。做法是在作品的 `<figure ...>` 开头标签里加一个 `data-full`：

```html
<figure class="work" data-full="assets/images/works-07-full.jpg">
```

- 网格里的图：放裁剪好的封面图（3:4 竖图）
- `data-full` 指向的图：完整长图原文件（竖长条）
- 两个文件都放进 `assets/images/`

## 8. 常见问题

| 现象 | 原因 | 解决 |
|------|------|------|
| 图片位置是个裂开的图标 | 文件名和 `src` 里写的不一致（大小写也算不一致） | 对照文件夹里的实际文件名，一字不差地改 `src` |
| 图片变形、比例不对 | `class` 用错了 | 看占位块原来写的比例，对照第 1 节表格 |
| 改完页面乱了 | 不小心删掉了 `<>`、`"` 或半行代码 | 按 `Ctrl+Z` 撤销；乱得太厉害就关文件选「不保存」，重新打开再改 |
| 保存后浏览器没变化 | 浏览器缓存 | 按 `Ctrl+F5` 强制刷新 |
| 图片显示但位置空了一截 | 没删占位说明文字 | 按第 4 节删掉 figcaption 行 |
| 视频传上去播放不了 | 格式不是 MP4 / 文件名有中文 | 转成 `.mp4`、改小写英文名 |
