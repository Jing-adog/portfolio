# 需求文档 v1.0

**状态：已确认（2026-08-17）**

## 1. 项目定位

面向面试官的新媒体运营个人作品集网站。用户是新媒体运营从业者，正在求职，需要把已有的 PDF 作品集（16 页纯图片版）做成一个网站，让面试官在手机上/电脑上点开链接即可完整了解其能力与成果。

## 2. 目标读者

- 面试官 / HR（招聘新媒体运营岗位）
- 可能通过微信、邮件收到链接，在手机或电脑上打开
- 阅读场景：快速浏览（30 秒 ~ 3 分钟），先看大标题和数字，再细读感兴趣的部分

## 3. 用户画像

新媒体运营，操盘平台：**小红书、抖音、微博、微信公众号、视频号（共 5 个平台）**。核心能力包括内容策划、数据分析、涨粉运营、视觉设计、短视频剪辑等。

## 4. 页面与板块需求

共 5 个页面（多页面结构，像参考站一样有导航分页）：

## 5. 风格需求

- 设计关键词：**大标题、高级排版、图文编排、杂志感、阅读体验**
- 参考网站：lattexplus.com（佛罗伦萨音乐节官网，Awwwards 获奖站），喜欢其 about 页的排布方式
- 配色决定（用户拍板）：**黑白 + 单一蓝点缀**（白底 / #111 近黑字 / #2779A7 蓝 / 浅灰辅助，照片自带彩色）
- 文风：人设小传风，专业但不僵硬；数据说话，不堆砌形容词

## 6. 功能需求

- 顶部导航：桌面横排（当前页高亮），<768px 汉堡菜单 + 全屏墨色菜单
- 页面淡入动画（滚动进入视口触发）
- KPI 数字滚动动画（1.2s，千分位，只滚一次）
- 作品灯箱（大图 + 上/下一张 + 计数 + 键盘操作）
- 账号页折叠展开（点平台名展开/收起，单开模式；无 JS 时仍可展开）
- 作品平台筛选（按钮切换，只显示所选平台作品）
- PDF 作品集下载（站内文件相对路径，零外部链接，所有访客可下载）
- 响应式：桌面杂志版式优先，手机正常阅读
- 尊重系统"减弱动态效果"设置

## 7. 非功能需求

- **零外部依赖**：无 CDN、无 npm 包、无网络字体、无框架
- **双协议可用**：file:// 双击打开可用 + GitHub Pages 部署可用
- **可维护性**：所有可编辑内容用 `<!-- CONFIG: xxx -->` 注释标注，非技术用户 Ctrl+F 搜索即可修改
- **浏览器兼容**：Chrome / Edge / Firefox 最新两个大版本；手机浏览器与微信内置浏览器
- **无障碍**：语义化标签、键盘可操作（灯箱/菜单）、焦点管理、对比度达标

## 8. 内容来源与填充计划

当前阶段（框架搭建）：全部内容用**优雅占位**（占位图 + 示例文字），用户后续填充。

内容填充分三步：
1. 用户在聊天里提供各板块文字内容 → AI 填入 CONFIG 标记处
2. 用 Node 脚本从桌面 PDF（`作品集（压缩版）.pdf`）提取 50 张图片到 assets/images/ → 替换占位图
3. 部署上线（见 dev-plan Step 10）

## 9. 验收标准

- 5 个页面全部可访问，导航跳转正常
- 手机（微信内置浏览器）打开链接浏览正常
- 用户按 README 能独立完成：改文字、换图片、部署到 GitHub Pages
- 风格符合关键词（大标题、杂志感、高级排版），不跑偏
