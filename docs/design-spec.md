# 设计规范 v1.0

**状态：已确认（2026-08-17）**

设计关键词：**大标题、高级排版、图文编排、杂志感、阅读体验**
参考：lattexplus.com about 页的排布方式（杂志索引、大字号、编辑式图文混排）

---

## 1. 配色令牌

| 令牌 | 值 | 用途 |
|------|------|------|
| `--c-bg` | `#FFFFFF` | 页面背景 |
| `--c-ink` | `#111111` | 主文字 / 近黑元素 |
| `--c-accent` | `#2779A7` | **唯一强调蓝**：大标题关键词、序号、图形色块、hover 态 |
| `--c-gray` | `#F2F2F2` | 引言块底、图片占位底 |
| `--c-line` | `#DDDDDD` | 发丝线、卡边框 |
| `--c-muted` | `#666666` | 次要说明文字（对比度 ≥4.6:1） |

**红线：**
- 强调色只有这一个蓝，禁止引入第二个彩色（照片除外）
- 小字正文（<24px）禁止使用 accent；accent 仅用于大字与图形元素（蓝字在白底上 4.6:1，小字反而不合格，大字因字号大而达标）

## 2. 字体配对（系统字体，零网络加载）

**关键技巧：西文字体放最前**，让 Windows / macOS 的数字、英文观感一致（数字是大字头的灵魂）。

| 用途 | 字体栈 | 备注 |
|------|--------|------|
| 大标题 / 数字 | `"Helvetica Neue", Helvetica, Arial, "PingFang SC", "Microsoft YaHei", "SimHei", sans-serif` | 黑体，weight 700 |
| 正文 / 导语 / 引言 | `Georgia, "Times New Roman", "Songti SC", "STSong", "SimSun", serif` | 宋体，行高放宽 |
| 首页 PORTFOLIO 大标题 | `"Poppins"（本地 woff2 拉丁子集 7.8KB）, "Arial Black", …, sans-serif` | 仅首页一行英文标题，weight 800；@font-face 本地加载零网络依赖，Arial Black 兜底 |

Windows 宋体较细 → 正文 ≥17px、行高 1.8–1.9。

## 3. 字号阶梯（CSS 变量，clamp 流式 + 静态兜底）

| 变量 | 值 | 用途 |
|------|------|------|
| `--text-hero` | `clamp(3rem, 9vw, 8rem)` | 首页 hero 主标题（48→128px） |
| `--text-display` | `clamp(2.5rem, 6vw, 5rem)` | 各页页首大标题 |
| `--text-section` | `clamp(2rem, 4vw, 3.5rem)` | 章节标题 |
| `--text-lead` | `clamp(1.25rem, 2vw, 1.75rem)` | 宋体导语 |
| `--text-body` | `17px`（min） | 正文，行高 1.8 |
| `--text-kpi` | `clamp(2.5rem, 3.6vw, 3.5rem)` | KPI 大数字（较初版收小：千分位长数字在 1/4 栏内不溢出） |
| `--text-small` | `14px` | 眉题 / caption / 脚注 |
| `--text-index` | `clamp(4rem, 10vw, 9rem)` | 首页目录索引大数字 |

## 4. 排版规则

| 元素 | 规格 |
|------|------|
| 眉题 `.eyebrow` | 英文大写，14px，字距 0.2em，accent 蓝或 muted |
| 章节序号 | Georgia italic + accent 蓝（如 `01`），与章节标题组合 |
| 大标题 | 黑体 700，字距 -0.02em，行高 1.05 |
| 正文段落 | 宋体 17px，行高 1.8，max-width 32em（阅读舒适） |
| 竖排 `.v-text` | `writing-mode: vertical-rl`，14px，字距 0.3em，muted |
| 年份时间线 | Georgia 大号（≥2rem）年份 + 黑体条目 |
| 发丝线 | 1px `--c-line`，用于分隔与卡顶边 |
| 引言块 | `--c-gray` 底 + 超大宋体引言（≥1.5rem）+ 署名 |

## 5. 布局网格

- 容器：`--container: 1440px`（宽容器）、`--container-narrow: 960px`（长文容器）
- 12 列网格，**不对称版式**：文字 col-5 + 图片 col-7 交错镜像，穿插满幅大图
- 垂直留白：`--section-pad: clamp(5rem, 12vw, 10rem)`（大量留白 = 杂志感）
- 区块内间距：`--block-pad: clamp(3rem, 6vw, 5rem)`

## 6. 组件规格

### 6.1 顶部导航（所有页面）
- sticky 顶栏，白底 98% 不透明度 + backdrop-blur
- 左：姓名 LOGO 黑体大写；右：5 个链接（首页/关于我/运营成果/运营账号/个人作品）
- 当前页：accent 蓝下划线（2px），硬编码 class，无需 JS
- <768px：汉堡按钮（3 条线）→ 全屏墨色菜单（大号链接 + 底部联系方式），Esc / 点链接关闭，滚动锁

### 6.2 页脚（所有页面）
- 发丝线顶边；超大标题「保持联系 / KEEP IN TOUCH」（--text-display）
- 联系方式列表（邮箱 / 微信 / 手机）
- 页面链接重复 + 版权行（muted 小字）

### 6.3 目录索引行（首页）
- 每行：大号 Georgia 序号（--text-index）+ 中文板块名（--text-display）+ 英文眉题 + 一句说明
- hover：整行灰底 + 箭头右移 8px

### 6.4 KPI 数据卡（运营成果页）
- 白卡（白纸面 + 轻投影）浮在米白纸面上，发丝线顶边；hover 顶线变蓝 + 投影加深 + 大数字变 accent 蓝
- 大数字（--text-kpi 黑体 700，tabular-nums 防抖）+ 小号 muted 单位（可含「+ / % / 万」等后缀）+ 标签 + 一句说明
- 桌面 4 列（col-3），<1024px 2×2，<480px 1 列
- 数字滚动：1.2s ease-out，进入视口触发、只滚一次；万级（≥10000）以上千分位，小数字保持原样（如「3000%」「4000+」）；无 JS / reduced-motion 时直接显示终值（HTML 里即为终值文本）

### 6.5 代表项目行
- 三个项目**平等陈列、无排名**：项目标题 + 平台标签（小号描边胶囊，可多个）+ 方向说明 + 项目描述 + 截图占位（16:9）
- 桌面两栏 grid（正文 / 截图），行间发丝线分隔；<768px 纵向堆叠（正文 → 截图）

### 6.6 折叠展开列表（运营账号页）
- 结构用原生 `<details>/<summary>`：无 JS 可展开，键盘可用
- 收起态每行：超大平台名（--text-section 黑体，展开时变 accent 蓝）+ 英文副题 + 账号名（可含归属说明，如「52HZ 酒品｜洛撒国际贸易有限公司」）+ 右侧箭头（收起 ▸ / 展开 ▾，hover 时箭头变蓝）
- 展开态结构：定位宋体导语句整行在上；下方两栏 —— 左（「实践快照」小眉题领起三列缩略图网格（**缩略图为主**，图下仅标题，无数据行；小红书 / 抖音快照为 9:16 竖图，微博为 16:9 且尺寸更大；网格 max-width 40rem，微博 48rem））右（截图占位 3:4，右列固定 18rem，网格右侧 padding 使截图重心稍左移构图不偏）；**截图与快照区块等高对齐**（flex 拉伸，3:4 尽量保持，宽度不足时居中裁切，替换图用 object-fit: cover）；**尺寸克制不铺满，留白呼吸**
- 视频号面板特例：不展示快照网格，改为嵌入视频行 —— 16:9 横屏视频居左（≤32rem）+ 两条 9:16 竖屏视频居右（各 11rem 列），**三条视频等高对齐**（视频文件放 assets/videos/，占位阶段用 9:16 / 16:9 占位块 + CONFIG 说明替换方法）
- 页首导语下带跳转提示小字：「完整案例详见 PDF 作品集 →」（链接 accent 蓝 + 加粗突出，hover 降透明度），做内容分流避免本页信息过载
- 行间发丝线分隔；**单开模式**：展开一个自动收起另一个（JS 监听 toggle 事件）；默认展开第一个
- 展开动画 0.3s ease 淡入；reduced-motion 无动画；移动端展开内容单列、代表作单列、收起行重排（平台名 + 箭头 / 账号信息换行）

### 6.7 作品画廊（审美习作页，2026-09-12 重构）

### 6.13 照片切换器（关于我页，2026-09-12 新增，替代单张 3:4 照片）
- 同一 3:4 视窗内轮换多张照片（初始 3 张占位），整体尺寸沿用竖图规则：宽 min(100%, 480px, 72vh×3/4)，高度不超过一屏
- 结构：3:4 视窗（ul.photo-slides，JS 门控 aspect-ratio）+ 控件条（左箭头 / 圆点组 / 右箭头，照片下方）
- 卡片堆叠造型：当前张居中（is-front，z 最高），后两张错位旋转露出边角（is-back-1 移 10/12px 转 1.5°、is-back-2 移 20/24px 转 3°），白纸面 + 投影呈叠纸感；移动端（≤768px）错位收小（6/8px 转 1.2°、10/14px 转 2°），避免背卡旋转角戳出视口（360px 实测横向溢出 11px）
- 卡片底部 caption 说明词（占位阶段「照片占位：…」）**只显示在最前一张卡上**（`.js .photo-slide:not(.is-front) .cap-meta` 隐藏），三张叠放时同一位置的 caption 不互相叠字；换真实照片后说明词删除
- 交互：箭头循环切换、圆点直达；切换动效 = **卡片洗牌**（前张倾斜退后、下一张回正，0.45s ease-out-soft 换位）；控件 hover 变蓝；**不自动轮播**（阅读场景由面试官手动翻看）
- 无障碍：按钮 aria-label、圆点 aria-current、非当前张 aria-hidden；键盘 Tab + Enter 可用
- 降级：无 JS 时照片纵向堆叠全部可见、控件隐藏；reduced-motion 无动画直接切换

## 7. 动效规格

| 动效 | 时长 | 缓动 | 触发 |
|------|------|------|------|
| 页面淡入 reveal | 0.6s | cubic-bezier(0.22, 1, 0.36, 1) | 滚动进入视口（IO），`--d` 级联延迟；运营成果 / 审美习作页触发线更深（rootMargin -22%），首屏仅页首，内容下滑才浮现 |
| KPI 计数 | 1.2s | ease-out | 进入视口，只滚一次，千分位 |
| 目录行 hover | 0.3s | ease | 灰底 + 箭头位移 |
| 汉堡全屏菜单 | 0.35s | ease-out | 开：上滑入；闭：下滑出 |
| 灯箱 | 0.25s | ease | 淡入 + 图片 scale 0.98→1 |
| 折叠展开 | 0.3s | ease | 展开内容淡入；箭头 ▸/▾ 切换，展开时平台名变 accent 蓝 |
| 大标题逐字入场 | 0.7s / 字 | cubic-bezier(0.22, 1, 0.36, 1) | 页面加载，每字 0.07s 交错 |
| 单字母 hover 弹跳 | 0.3s | cubic-bezier(0.34, 1.56, 0.64, 1) | 悬浮单字母上移 0.06em + 变 accent 蓝 |
| 照片切换（卡片洗牌） | 0.45s | ease-out-soft | 前张倾斜退后、下一张回正，卡片换位；圆点/箭头 hover 变蓝 |
| 段落 hover 蓝线 | 0.3s | ease | 关于我正文段落：左侧蓝线 + 极淡蓝底 |

**无障碍：** 所有动效包在 `@media (prefers-reduced-motion: reduce)` 里降级为无动画直接显示。

## 8. 占位图规格（框架阶段，2026-09-12 定稿为 CSS 占位块方案）

- 占位块 `.ph`（CSS 实现，零图片文件，替代初版 SVG 占位图计划）：`--c-gray` 底 + 1px `--c-line` 边 + 居中灰字说明（如「作品占位 · 01」「照片占位 · 形象照 3:4」）
- 比例类：`.ph--wide`（16:9）、`.ph--portrait`（3:4，竖图限高 72vh）、`.ph--9x16`（9:16 竖屏）、`.ph--square`（1:1，max-width 480px）
- 内容填充 = 占位块换成真实媒体元素、class 不变：`<img class="ph ph--portrait" src="assets/images/xxx.jpg" alt="说明">` / `<video class="ph ph--9x16" controls src="assets/videos/xxx.mp4">`；`img.ph, video.ph { display: block; padding: 0; object-fit: cover; }` 按原比例自动裁切填满，无需手写样式（display: block 覆盖 .ph 的 flex，否则位图按原始尺寸居中渲染、object-fit 失效）
- 每处占位配 CONFIG 注释说明预期内容与替换方法；完整教程见 docs/content-guide.md
- 占位旁的 `<figcaption>`「××占位：…」说明文字在换真实图后删除

| 断点 | 变化 |

## 10. 无障碍与对比度

- 语义化：header/nav/main/section/footer/dl/time/figure
- 键盘：导航、灯箱、全屏菜单全部可键盘操作；灯箱关闭后焦点还原
- 对比度：正文 ink-on-bg 19:1；muted 灰字 5.7:1；accent 蓝大字 ≥4.6:1；小字禁用 accent
- `prefers-reduced-motion` 全量降级
- 图片必须有 alt；占位图 alt 写预期内容
