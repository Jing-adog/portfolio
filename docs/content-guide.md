# 内容填写指南（Content Guide）

**给江宇晴的逐页填写教程。** 看完第 0–2 节，你就掌握了 90% 的修改方法；第 3 节是各页速查，第 4–5 节是 PDF 更新与常见问题。

---

## 0. 改前必读

### 用什么工具

- **推荐 VS Code**（免费）：打开整个文件夹，左侧能看到全部文件，双击即可编辑
- 也可以用记事本：右键 html 文件 →「打开方式」→ 记事本

### 三个基本动作

1. **搜索**：按 `Ctrl + F`，输入 `CONFIG`，回车跳转（再按一次跳到下一处）
2. **修改**：只改标签中间的文字（见第 1 节红线）
3. **保存**：`Ctrl + S`，然后切到浏览器按 `Ctrl + F5` 强制刷新看效果

### 文件对应表

| 想改的内容 | 打开这个文件 |
|-----------|-------------|
| 首页（开屏 / 目录 / 精选作品） | `index.html` |
| 关于我（照片 / 自我介绍 / 经历 / 能力） | `about.html` |
| 运营成果（数据卡 / 代表项目） | `achievements.html` |
| 运营账号（4 个平台面板） | `accounts.html` |
| 审美习作（9 件作品） | `works.html` |
| 下载用的 PDF | 不用改代码，覆盖文件（见第 4 节） |

### 改之前先备份

把整个「作品集杂志版」文件夹复制一份改名为「作品集杂志版-备份」，改坏了随时从备份拷回。

## 1. 改文字（最常见的操作）

### CONFIG 注释分类

每处可改内容上方都有一行注释告诉你「改这里」。全站共 **108 处**，按前缀分类：

| 前缀 | 含义 | 例子 |
|------|------|------|
| `CONFIG: 基本信息` | 姓名、版权行 | 导航左上角姓名 |
| `CONFIG: 文字` | 标题、段落、条目 | 页首大标题、导语 |
| `CONFIG: 数字` | KPI 数据 | 16 万+、3000% |
| `CONFIG: 图片` | 图片文件名 | 照片、截图 |
| `CONFIG: 视频` | 视频文件 | 视频号面板 |
| `CONFIG: 链接` | 邮箱、手机、微信 | 页脚联系方式 |
| `CONFIG: 文字/图片` | 作品条目（标题+图） | 审美习作页 |

### 一个完整例子

打开 `works.html`，`Ctrl+F` 搜「一句话导语」，你会看到：

```html
<!-- CONFIG: 文字 — 一句话导语 -->
<p class="lead">绘画、摄影、版式排版与海报习作。在创作中打磨审美感知。</p>
```

把 `<p class="lead">` 和 `</p>` 中间的文字改成你的新文案，保存，刷新。完成。

### 改文字红线

1. **只改标签中间的文字**，尖括号 `< >`、`class="…"`、`href="…"` 不要动
2. **引号要成对**：改引号里的内容时（如邮箱），前后两个引号都保留
3. **首页跑马灯**：关键词写了两段（一模一样，为了无限滚动不断档），改的时候**两段要改成一样**
4. 首页大标题 `PORTFOLIO` 是逐字拆开的（每个字母一个 `<span>`），要改的话让 AI 帮你改，不要手动动字母

## 2. 换图片（最重要的一节）

> **零基础第一次操作**：先看 [embed-guide.md](embed-guide.md) —— 从安装 VS Code、找文件、复制粘贴到刷新验证，每一步都写了「在哪点、看到什么、输入什么」。本节是速查版，适合熟练后翻阅。

### 第一步：把图片放进文件夹

图片文件放进 `assets/images/` 文件夹。命名规则：

- **小写英文 + 数字 + 连字符**，例如 `works-01.jpg`、`about-1.jpg`、`xiaohongshu-1.png`
- ❌ 不要中文、空格、大写（部署到 GitHub Pages 后会打不开）

### 第二步：占位块换成图片

每个占位块长这样：

```html
<div class="ph ph--portrait">作品占位 · 04</div>
```

把它**整个替换**成（class 原样保留，只把 div 换成 img）：

```html
<img class="ph ph--portrait" src="assets/images/works-04.jpg" alt="氛围感纪实抓拍">
```

- `src` 写你图片的文件名；`alt` 写一句图片说明（给面试官读屏和图片加载失败时看）
- **图片会自动按原来的比例裁切填满，不用自己裁图**（超出部分自动裁掉，不会变形）
- 换完之后，把占位块旁边的说明文字（如「照片占位：个人形象照」）**删掉**

### 比例对照表

| class | 比例 | 用在 |
|-------|------|------|
| `ph--wide` | 16:9 横图 | 首页精选 3 格、运营成果截图、微博快照、横屏视频 |
| `ph--portrait` | 3:4 竖图 | 关于我照片、账号主页截图、摄影 / 海报作品 |
| `ph--9x16` | 9:16 竖屏 | 小红书 / 抖音快照、竖屏视频 |
| `ph--square` | 1:1 方图 | 绘画插画作品 |

> 提示：图片比例和 class 不一致也没关系，自动裁切填满，选最接近的比例即可。

**视频替换方法**（把视频文件放进 `assets/videos/`，然后）：

```html
<!-- 原来 -->
<div class="ph ph--wide">视频占位 · 16:9</div>
<!-- 换成 -->
<video class="ph ph--wide" controls src="assets/videos/channels-01.mp4"></video>
```

竖屏两条 class 用 `ph--9x16`。换完删掉下方「视频占位・…」说明文字。

### 审美习作 works.html

| 内容 | 搜索关键词 | 改法 |
|------|-----------|------|
| 9 件作品 | `CONFIG: 文字/图片 — 作品 01` 到 `作品 09` | 标题改 `work-title`，说明改 `work-meta` |
| 作品缩略图 | 同上，每件作品注释里都有说明 | 第 2 节方法：方图 `ph--square`、照片与海报 `ph--portrait` |
| **灯箱大图**（重要） | 作品注释里写「加 data-full」 | 缩略图换好后，在 `<figure>` 标签上加大图路径（见下方） |

**灯箱大图方法**：作品 07/08 是长图，其他作品点开灯箱默认显示大占位块。想让灯箱显示真实大图，在作品最外层的 `<figure class="work" ...>` 上加：

```html
<figure class="work" data-full="assets/images/works-01.jpg">
```

长图作品（07/08）已有 `data-long`，保留即可——灯箱里可以上下滚动看完整长图。

## 5. 常见问题

**Q：图片显示不全 / 变形了？**
A：检查 img 标签上的 class 是否保留（如 `ph--portrait`）。图片是「裁切填满」而不是「缩放变形」，构图主体尽量放图片中央。

**Q：灯箱点开没有大图？**
A：检查 `<figure class="work">` 上有没有 `data-full="assets/images/xxx.jpg"`，路径要和实际文件名完全一致（小写）。

**Q：改了文字但浏览器没变化？**
A：按 `Ctrl + F5` 强制刷新；还不行就检查文件保存了没有。

**Q：改坏了怎么办？**
A：从「作品集杂志版-备份」文件夹把同名文件复制回来覆盖。

**Q：一张图片想在两个地方用？**
A：没问题，两处 `src` 写同一个文件名即可。
