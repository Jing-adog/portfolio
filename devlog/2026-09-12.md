- 审美习作页组间距「一直挤」：选择器 `.work-group + .work-group` 与 HTML 结构不匹配（组标题实际是 `.work-group-title`，无 `.work-group` 包裹），规则从未生效 → 改为 `.gallery + .work-group-title`。教训：CSS 选择器改动后需在浏览器确认命中，不能只看数值
- img.ph 裁切不生效（测试页实测发现）：`.ph` 基础类是 `display: flex`，img 设 flex 后位图退化为匿名 flex 子项按原始尺寸居中渲染，object-fit: cover 失效 → `img.ph, video.ph` 补 `display: block` 覆盖。教训：替换元素上 display 变化会改变 object-fit 的作用对象
